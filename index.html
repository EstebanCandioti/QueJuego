Configurar tablero

En modo local, la lista queda guardada en este navegador. Podés usar los dos perfiles desde acá.

Activar modo compartido
  1. Publicá este archivo como index.html en GitHub Pages o en un proyecto estático de Vercel.
  2. Creá un proyecto en Supabase. Copiá la URL del proyecto y su clave sb_publishable_… desde Connect o API Keys.
  3. Completá los campos y generá la instalación. Ejecutá el SQL una vez en SQL Editor → New query.
  4. Guardá los dos enlaces en un lugar privado y compartí uno con tu amigo. Abran cada uno su enlace después de ejecutar el SQL.

Los enlaces dan acceso a cada perfil. El tablero compartido empieza vacío y el backlog local sigue en este navegador.

Copiá el SQL al editor de Supabase y ejecutalo antes de abrir los enlaces.

Cambiar mi nombre

Si ya activaron el tablero compartido con la versión anterior, ejecutá este SQL una vez en el SQL Editor del mismo proyecto Supabase. Después podés guardar tu nombre desde acá.
